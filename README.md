Registro de Inscripción a Gimnasio

Descripción

Este ejercicio consiste en crear una clase en Java que represente la membresía de un socio de gimnasio. Permite registrar sus datos y controlar si la cuota mensual está pagada o pendiente.

Funcionamiento

* Registrar el DNI y nombre completo del socio.
* Inicializar la cuota como pendiente de pago.
* Utilizar el método `pagarCuota()` para marcar la cuota como pagada.
* Utilizar el método `registrarVencimiento()` para volver a marcarla como pendiente.
* Mostrar la información del socio y el estado de su cuota por consola.

Conceptos utilizados

* Clases y objetos.
* Encapsulamiento.
* Constructores.
* Métodos.
* Atributos booleanos.
* Modificación de estados.

Ejemplo

Se crea una membresía para un socio, se simula el pago de la cuota y se muestra su información actualizada, indicando si se encuentra al día con el gimnasio.
